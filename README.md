# EMOM-тренировки

Мини-приложение (PWA) для EMOM-тренировок с ротацией из 8 упражнений. Чистый HTML/CSS/JavaScript, без сборки и зависимостей. Работает офлайн, все данные хранятся на устройстве (localStorage).

## Структура

```
index.html             разметка и подключение
manifest.webmanifest   манифест PWA
sw.js                  service worker (офлайн-кэш)
css/styles.css         стили, светлая и тёмная тема
js/app.js              экраны и логика интерфейса
js/exercises.js        упражнения, ротация, подсказки по прогрессии
js/store.js            хранение данных, экспорт и импорт
js/timer.js            расчёт таймера по Date.now()
js/feedback.js         звук (Web Audio API) и вибрация
js/wakelock.js         запрет затухания экрана (Screen Wake Lock)
js/chart.js            SVG-графики прогресса
icons/                 иконки приложения
```

## Запуск локально

Нужен любой статический HTTP-сервер: service worker не работает при открытии файла через `file://`.

```bash
# Python
python -m http.server 8000
# или Node.js
npx serve .
```

Откройте http://localhost:8000. На `localhost` service worker работает и без HTTPS.

Чтобы открыть приложение с телефона в той же Wi-Fi-сети, зайдите на `http://<IP-компьютера>:8000`. Офлайн-режим и установка там работать не будут, потому что для них нужен HTTPS. Для полноценной проверки задеплойте приложение на GitHub Pages.

## Деплой на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки (`index.html` должен лежать в корне):
   ```bash
   git init
   git add .
   git commit -m "EMOM PWA"
   git branch -M main
   git remote add origin https://github.com/<логин>/<репозиторий>.git
   git push -u origin main
   ```
2. В репозитории откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
4. Через минуту-две приложение будет доступно по адресу `https://<логин>.github.io/<репозиторий>/`.

Все пути в приложении относительные, поэтому оно работает и из подпапки репозитория.

### Обновление приложения

Service worker отдаёт файлы из кэша. **После любых изменений увеличьте `VERSION` в `sw.js`** (например, `v1.0.1`), иначе пользователи продолжат видеть старую версию. Новая версия подхватится при следующем открытии приложения (иногда нужно закрыть его и открыть снова).

## Установка на телефон

### iPhone (Safari)
1. Откройте адрес приложения **в Safari**.
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой вверх).
3. Выберите **«На экран "Домой"»**, затем «Добавить».

Что стоит знать про iPhone:
- Вибрация в Safari не поддерживается, сигналы будут только звуковые.
- Если включён беззвучный режим (переключатель на корпусе), звука не будет.
- Блокировка затухания экрана работает начиная с iOS 16.4. На более старых версиях на время тренировки увеличьте время автоблокировки.
- Данные приложения на главном экране и в Safari хранятся раздельно. Регулярно делайте резервную копию: «Настройки → Экспорт в JSON».

### Android (Chrome)
1. Откройте адрес приложения в Chrome.
2. Нажмите «Установить приложение» во всплывающей подсказке или в меню ⋮ выберите **«Добавить на главный экран» / «Установить приложение»**.

## Как это работает

- **Ротация.** Хранится номер следующего упражнения, календарь не используется. После сохранения тренировки ротация сдвигается на одно упражнение вперёд, поэтому пропущенный день ничего не сбивает. Если заменить упражнение вручную, замена займёт «сегодняшний» слот, а следующим всё равно пойдёт упражнение, которое было следующим по ротации.
- **Прогрессия.** Если в прошлый раз план выполнен полностью (все минуты, в каждой не меньше повторений, чем по плану), приложение предлагает +1 минуту. После 20 минут оно предлагает +1 повторение в минуту и возврат к 10 минутам. Если план не выполнен, предлагает повторить его.
- **Таймер.** Время считается по меткам `Date.now()`, поэтому подтормаживание или ненадолго погасший экран не сбивают отсчёт. Незавершённая тренировка сохраняется и восстановится, если приложение перезапустится.
- **Сигналы.** В начале каждой минуты звучит двойной сигнал с вибрацией, за 3, 2 и 1 секунду до неё звучат короткие сигналы.
